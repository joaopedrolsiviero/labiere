# Empório Lá Biere

Landing page de uma adega e conveniência de bairro em Goiânia, feita para levar o visitante ao contato pelo WhatsApp e à localização da loja.

**Demo:** https://joaopedrolsiviero.github.io/labiere/

> Projeto de portfólio. O estabelecimento encerrou as atividades, e o telefone e os depoimentos exibidos na página são ilustrativos.

![Tela inicial](docs/screenshot.png)

## O que tem na página

- Seções de apresentação, diferenciais, localização com mapa e contato
- Botão flutuante e chamadas para conversa no WhatsApp com mensagem pronta
- Formulário que monta a mensagem com o nome do visitante e abre o WhatsApp
- Layout responsivo para celular e computador

## Destaques técnicos

- **Sem frameworks:** HTML, CSS e JavaScript puros, sem etapa de build
- **SEO:** título e descrição otimizados, Open Graph e dados estruturados em JSON-LD (schema.org, tipo `Store`)
- **Acessibilidade:** HTML semântico e rótulos `aria` nos elementos de navegação e ação
- **Desempenho:** imagens em WebP, mapa com carregamento sob demanda e fontes com `preconnect`

## Como rodar

Não há dependências. Clone o repositório e abra o `index.html` no navegador.

```bash
git clone https://github.com/joaopedrolsiviero/labiere.git
cd labiere
```
